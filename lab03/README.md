### Задание 1 **(3)**
* **Тип в программировании** — атрибут объекта данных, задающий множество допустимых значений и методы для работы с ними.
* **Статическая типизация** — вид типизации, при котором тип объекта данных определяется в момент трансляции.
* **Динамическая типизация** — вид типизации, при котором тип объекта данных определяется на этапе выполнения программы в момент создания или присваивания значения.
* **Неявная типизация** — автоматическое определение типа объекта данных на этапе трансляции по тексту программы.
* **Явное преобразование типа** — метод преобразования, который указан в программе в виде вызова функции или в виде операции.
* **Неявное преобразование типа** — метод преобразования, который не присутствует в программе в виде конкретного указания, однако транслятор сам подставляет требуемый метод.
* **Сильная типизация** — характеристика языка, при которой он не содержит (или почти не содержит) правил неявного преобразования типа.
* **Слабая типизация** — характеристика языка, при которой он содержит большое число правил неявного преобразования типа и допускает каламбуры типизации.

### Задание 2 **(3)**
### 1. Преобразования при присваивании
* Значение правого операнда автоматически приводится к типу левого операнда.
* При вызове функции фактический параметр приводится к типу формального параметра.
* Из вещественных типов в целочисленные: всегда происходит отсечение дробной части.

### 2. Преобразования при арифметических действиях
* Если длины обоих типов меньше int, то они автоматически преобразуются к int.
* Если операнды имеют типы разной длины, то меньший тип всегда преобразуется к большему.
* Если типы имеют равную длину, но один из них знаковый, а другой беззнаковый, то знаковый приводится к беззнаковому.
* Если один операнд целый, а другой вещественный, то целый всегда приводится к вещественному.

### 3. Преобразования с логическими значениями
* Преобразование любого типа в bool: число 0 преобразуется в false, а любые другие значения преобразуются в true.
* Преобразование из bool в другие типы: значение false дает 0, а значение true дает 1.
* Результат условного выражения в инструкциях ветвления (if) и циклов всегда приводится к логическому типу.
* Если оператор требует логического значения (логические операции), то операнды автоматически приводятся к логическому типу.

#include <iostream>

int main() {

Программа вывела на экран следующие обозначения типов:

2. **Переменная `b` имеет тип `bool`.** Оператор `&&` является логическим. Он работает напрямую с логическими значениями и сразу возвращает логический тип `bool` без приведения к целым числам.

### Задание 5. **(2)**
### Исходный код программы:
```cpp
#include <iostream>

int main() {
    typedef unsigned long long ull;
    ull a = 5000000000ULL;

    auto b = a; 
    decltype(b) c = 10;

    double d = 5.75;
    int e = static_cast<int>(d);

    std::cout << "Size of a: " << sizeof(a) << " bytes" << std::endl;
    std::cout << "Value of e: " << e << std::endl;

    return 0;
}
```

### Результат работы программы:
```text
Size of a: 8 bytes
Value of e: 5
```

### Объяснение вывода программы:
* **Почему программа вывела 8 bytes:** Оператор `sizeof` измерил размер переменной `a` в памяти. Так как она принадлежит типу `unsigned long long`, на компьютере она весит ровно 8 байт.
* **Why программа вывела 5:** Переменная `e` получила значение через явное приведение типов `static_cast<int>`. При переводе вещественного числа в целое вся его дробная часть полностью отсекается, поэтому от `5.75` осталась только пятерка.

### Описание инструментов в коде:
* `typedef` — делает короткое имя `ull` для длинного типа.
* `auto` — автоматически определяет тип для `b` по типу переменной `a`.
* `decltype` — берет тип переменной `b` и делает точно такой же тип для переменной `c`.

### Задание 6 **(2)**
### Исходный код программы:
```cpp
#include <iostream>

int main() {
    int a = -1, b = 1;
    unsigned int c = 1;
    std::cout << a * b << std::endl;
    std::cout << a * c << std::endl;
    return 0;
}
```

### Результат работы программы:
```text
-1
4294967295
```

### Объяснение результатов работы (по правилам лекции):
1. **Первый вывод (`a * b`):** Обе переменные имеют обычный знаковый тип `int`. Умножение `-1 * 1` происходит стандартно, поэтому на экран выводится корректный результат `-1`.
2. **Второй вывод (`a * c`):** Переменная `a` имеет знаковый тип `int`, а переменная `c` — беззнаковый `unsigned int`. Если типы имеют равную длину, но один знаковый, а другой беззнаковый, знаковый тип автоматически приводится к беззнаковому. В этот момент переменная `a` (число -1) превращается в максимально возможное беззнаковое число для 32-битной памяти — `4294967295`. При умножении на 1 оно же и выводится на экран.

### Ответ на дополнительный вопрос:
* **Что произойдет, если заменить типы на `short` и `unsigned short`:**
  * Если мы поменяем типы, то обе строчки кода выведут на экран обычное число **`-1`**.
  * **Почему так происходит:** Если длины обоих типов меньше, чем у стандартного `int`, то перед любым арифметическим действием компилятор сначала автоматически преобразует их оба к типу `int`. В этот момент и `short a = -1`, и `unsigned short c = 1` становятся обычными знаковыми числами `int`. Умножение происходит внутри знакового типа `int`, и никакого превращения в огромное беззнаковое число не случается.


### Задание 7 **(2)**
### Исходный код программы:
```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 7, y = 4;
    long double d = 0.25;
    cout << (x / y) / d << endl;
    cout << (x / d) / y << endl;

    long a = 200000, b = 200000;
    long long c = 200000;
    std::cout << (a * b) * c << std::endl;
    std::cout << a * (b * c) << std::endl;
    return 0;
}
```

### Результат работы программы:
```text
4
7
-1863462912
8000000000000000
```

### Объяснение результатов работы (по правилам лекции):

#### 1. Первая часть (деление с переменными x, y, d):
* **Выражение `(x / y) / d` вывело 4:** Первым делом в скобках делятся два целых числа `int` (`7 / 4`). При делении целых чисел дробная часть отсекается, поэтому результат равен `1`. Затем эта единица делится на вещественное `d` (`1 / 0.25`). Целое число приводится к вещественному, и получается итоговый ответ `4`.
* **Выражение `(x / d) / y` вывело 7:** В первых скобках целое число делится на вещественное `long double` (`7 / 0.25`). `int` сразу приводится к `long double`, поэтому деление происходит без потерь и дает точный результат `28`. Затем `28` делится на целое `y` (`28 / 4`), что дает итоговый правильный ответ `7`.

#### 2. Вторая часть (умножение с переменными a, b, c):
* **Выражение `(a * b) * c` выдало неверный результат:** Сначала в скобках перемножаются две переменные типа `long` (`200000 * 200000`). Результат равен 40 миллиардам, но тип `long` в Windows вмещает числа только до 2 миллиардов. Происходит переполнение памяти, и получается случайное испорченное число. Только после этого оно умножается на большой тип `long long c`, но результат уже испорчен.
* **Выражение `a * (b * c)` выдало правильный результат:** Первым делом в скобках перемножаются `long b` и `long long c`. Меньший тип `long` автоматически приводится к большему `long long`. Умножение происходит внутри огромного типа `long long`, который легко вмещает 40 миллиардов без всяких потерь. Затем полученное число умножается на `long a` (который тоже расширяется до `long long`), давая правильный итоговый ответ.


### Задание 8 **(2)**
### Исходный код программы:
```cpp
#include <iostream>

int main() {
    int x = 5, y = 5, z = 10;
    bool result = ((x == y) + (x == z) == true);
    std::cout << std::boolalpha << result << std::endl;
    return 0;
}
```

### Перечисление всех случаев, когда выражение истинно:
Выражение принимает значение `true` в следующих двух случаях:
1. Когда `x` равно `y`, но при этом `x` не равно `z` (например: `x = 5, y = 5, z = 10`).
2. Когда `x` равно `z`, но при этом `x` не равно `y` (например: `x = 5, y = 10, z = 5`).

Если `x`, `y` и `z` равны между собой или если `x` не равно ни одному из них, выражение вернет `false`.

### Объяснение работы программы:
* Каждое сравнение в скобках (`x == y` и `x == z`) дает результат типа `bool` (`true` или `false`).
* Оператор сложения `+` требует целых чисел. По правилам неявного преобразования типов в C++, значения `bool` приводятся к типу `int`: `false` становится `0`, а `true` становится `1`.
* Чтобы итоговое сравнение с `true` (которое тоже приводится к числу `1`) вернуло истину, сумма левой части должна быть строго равна `1`. Это возможно только тогда, когда сработало ровно одно из двух сравнений (то есть `1 + 0` или `0 + 1`).


### Задание 9 **(2)**
Было исследовано поведение выражения `x == y == z` для целых чисел, равных единице (`x = 1, y = 1, z = 1`). Результаты оказались разными для каждого языка.

### 1. Язык Python
* **Результат:** Программа успешно работает и выводит `True`.
* **Объяснение:** В Python реализованы цепочечные сравнения. Выражение `x == y == z` автоматически раскрывается транслятором как `(x == y) and (y == z)`. Так как 1 равно 1 и 1 равно 1, итоговый результат получается истинным.

### 2. Язык C++
* **Результат:** Программа успешно компилируется и выводит `true`.
* **Объяснение:** Вычисление идет слева направо. Сначала считается первая часть `x == y` (`1 == 1`), что дает логическое `true`. Затем это `true` сравнивается с переменной `z` (`true == 1`). По правилам неявного приведения типов C++, логическое `true` превращается в целое число `1`. Операция превращается в `1 == 1`, и итоговый результат становится истинным.

### 3. Язык Java
* **Результат:** Ошибка компиляции `error: incomparable types: boolean and int`.
* **Объяснение:** Вычисление идет слева направо. Первая часть `x == y` возвращает логический тип `boolean` (значение `true`). Далее Java пытается сравнить полученный `boolean` со значением `int z` (`true == 1`). Поскольку в Java действует сильная типизация, неявное сравнение логического типа с числовым строго запрещено, и транслятор выдает ошибку.
