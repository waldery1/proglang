### Задание 5. **(2)**

*Объясните работу фрагмента программы на С++. В частности, почему* $x+x-x=x$, *но при этом*
$(x\cdot 2)/2\neq x$? *В отчете надо привести вычисления, приводящие к ответу.*

### Исходный код программы:
```cpp
#include <iostream>

int main() {
    unsigned short x = 40000;
    unsigned short y = x + x;
    unsigned short z = x * 2;
    y = y - x;
    z = z / 2;
    std::cout << y << " " << z << std::endl;
    return 0;
}
```

### Результат работы программы:
```text
40000 7232
```

### Математическое обоснование вычислений:
Тип `unsigned short` занимает 16 бит. Его диапазон значений — от 0 до 65535. Любые вычисления при выходе за границы диапазона происходят по модулю \(2^{16} = 65536\) (арифметика по модулю).

1. **Почему \(x + x - x = x\) (в коде `y` вернулся к 40000):**
   * Сначала вычисляется сумма: \(40000 + 40000 = 80000\).
   * Число превысило 65535. Из-за переполнения берется остаток: \(80000 - 65536 = 14464\). Переменная `y` сохранила число `14464`.
   * Затем выполняется вычитание: \(14464 - 40000 = -25536\).
   * Результат отрицательный. В кольце беззнаковых чисел он приводится по модулю 65536: \(-25536 + 65536 = 40000\).
   * **Вывод:** Операция вычитания является обратной для сложения. При движении по замкнутому кольцу целых чисел вычитание вернуло значение назад в ту же точку без потери данных.

2. **Почему \((x \cdot 2) / 2 \neq x\) (в коде `z` стал равен 7232):**
   * Вычисляется умножение: \(40000 \cdot 2 = 80000\). Из-за переполнения по модулю 65536 в памяти остается число `14464`.
   * На этом этапе старший бит числа (который улетел за пределы 16 бит) полностью стирается и теряется навсегда.
   * Далее выполняется деление: \(14464 / 2 = 7232\).
   * **Вывод:** Деление на 2 просто делит то испорченное число, которое осталось в памяти. Оно не способно восстановить старший бит, потерянный при переполнении во время умножения. Поэтому обратного возврата к 40000 не происходит.

### Задание 8 **(2)**

*Найдите результаты вычисления следующих выражений без использования компьютера
или калькулятора. Процесс вычислений должен быть отображен в отчете.*
* `(1000 & 100) << 10`
* `(1000 >> 4) & 15`
* `~1234 + 1234`
* `(1000 ^ 500) & 63`
* `(100 << 3) + (100 >> 3)`

Все вычисления выполнены аналитическим путем без использования компьютера.

### 1. Выражение `(1000 & 100) << 10`
* **Побитовое И в скобках:** Переведем числа в двоичную систему:
  `1000` = `1111101000`
  `100`  = `0001100100`
  Применяем операцию `&` (биты остаются единицами только там, где у обоих чисел стоят единицы): получаем `0001100000` (это десятичное число `96`).
* **Битовый сдвиг влево:** Операция `96 << 10` означает сдвиг на 10 разрядов влево, что эквивалентно математическому умножению на \(2^{10} = 1024\).
  \(96 \cdot 1024 =\) **`98304`**

### 2. Выражение `(1000 >> 4) & 15`
* **Битовый сдвиг вправо в скобках:** Операция `1000 >> 4` означает сдвиг на 4 разряда вправо, что эквивалентно делению на \(2^4 = 16\) с отсечением остатка.
  \(1000 / 16 =\) **`62`**
* **Побитовое И:** Переведем числа в двоичную систему:
  `62` = `111110`
  `15` = `001111`
  Применяем операцию `62 & 15`: накладывается маска, и остаются только четыре младших бита `001110` (это десятичное число **`14`**).

### 3. Выражение `~1234 + 1234`
* **Побитовое отрицание:** По правилам лекции о представлении отрицательных чисел в дополнительном коде, для любого целого числа `x` операция поразрядного инвертирования `~x` математически дает результат \(-x - 1\).
* **Итоговый расчет:** Подставляем это правило в выражение:
  \((-1234 - 1) + 1234 = -1235 + 1234 =\) **`-1`**

### 4. Выражение `(1000 ^ 500) & 63`
* **Операция маски:** Число 63 в двоичной системе записывается как шесть единиц (`111111`). Операция `& 63` работает как маска: она полностью обнуляет все старшие биты, оставляя без изменений только последние 6 бит результата.
* **Исключающее ИЛИ для младших бит:** Возьмем последние 6 бит у чисел:
  `1000` (последние 6 бит) = `101000`
  `500`  (последние 6 бит) = `110100`
  Применяем операцию `^` (разные биты дают 1, одинаковые дают 0): получаем `011100` (это десятичное число **`28`**).

### 5. Выражение `(100 << 3) + (100 >> 3)`
* **Левый сдвиг:** Операция `100 << 3` эквивалентна быстрому умножению на \(2^3 = 8\).
  \(100 \cdot 8 = 800\)
* **Правый сдвиг:** Операция `100 >> 3` эквивалентна быстрому делению на \(2^3 = 8\) с округлением вниз.
  \(100 / 8 = 12\)
* **Итоговое сложение:** Складываем две полученные части:
  \(800 + 12 =\) **`812`**

## Практикум по программированию

## Справочник по функциям и типам

* **`input()`**
  * **Параметры:** вызывается без аргументов.
  * **Возвращаемое значение:** строка, считанная со стандартного ввода.
  * **Тип данных:** `str`.
* **`.split()`**
  * **Параметры:** вызывается без аргументов (разделитель по умолчанию — пробел).
  * **Возвращаемое значение:** список, состоящий из отдельных слов (подстрок).
  * **Тип данных:** `list` (содержит элементы `str`).
* **`int()`**
  * **Параметры:** принимает один обязательный аргумент (строку или число).
  * **Возвращаемое значение:** целое число.
  * **Тип данных:** `int`.
* **`len()`**
  * **Параметры:** принимает один обязательный аргумент (строку, список, кортеж).
  * **Возвращаемое значение:** количество элементов или символов.
  * **Тип данных:** `int`.
* **`print()`**
  * **Параметры:** принимает переменное число позиционных аргументов для вывода. Может принимать именованные параметры, такие как `sep` (строка-разделитель) и `end` (строка, завершающая вывод).
  * **Возвращаемое значение:** не имеет возвращаемого значения (возвращает неявный `None`).
  * **Тип данных:** `NoneType`.
* **`min()` / `max()`**
  * **Параметры:** принимают несколько позиционных аргументов (или один итерируемый объект).
  * **Возвращаемое значение:** наименьшее или наибольшее значение соответственно.
  * **Тип данных:** совпадает с типом переданных аргументов (в наших задачах — `int`).

name1, name2, name3 = input().split()
