### Задание 1 **(2)**
*Оцените работу следующих фрагментов программ. Какие из них обладают неоднозначным поведением? Почему?*
```
int x=10, y=3;
std::cout << std::min(x=15, x+y);
```
```
int x=10, y=3;
x=15, y+=x, x+=y;
```
```
int x=10, y=9;
if (x>y++ && y++>9)
  cout << "yes" << endl;
cout << y;
```

*Тексты программ разместите в папке с номером задания*

Фрагмент первой программы обладает неодназначым поведением. Вызвается функция min, а порядок вычисления параметров функции не определен. Компилятор может начать вычисления как с "x=15", так и с "x+y". Если сначала вычислится левая часть, то x уже будет равен 15, следовательно x + y = 18. А если правая, то x все также равен 10 и x + y = 13.

Фрагмент второй программы обладает однозначным поведением. Так как в фрагменте есть оператор "запятая", все строго вычисляется с лева направо. Поэтому x становится равный 15, затем выполняется y += x (y = 18), в конце выполняется x += y (x = 33). 

Фрагмент третьей программы обладает однозначным поведением. Логический оператор && вычисляется строго слева направо - сначала проверяется левая часть (10 > 9) дает истину, y++ возвращает текущее значение для сравнения, а сам y увеличивается на 1 и становится равным 10. Так как левая часть истина, обязательно проверяем правую. В правой части 10 > 9 также дает истину, поэтому на экран выводится "yes", а y еще раз увеличивается на 1 и становится равным 11.

### Задание 2 **(2)**
*Как записать следующие строки программы на С++ в виде одного
выражения? Приведите несколько способов, в том числе с использованием операторов инкремента.*
*Проверьте работу написанных программ*
```
x=x+1;
z=z+2*x+3*y;
y=y+1;
```
*Тексты программ разместите в папке с номером задания*

1 способ с использованием операторов инкремента
```
#include <iostream>
using namespace std;

int main() {
    int x = 5, y = 2, z = 10;
    z += 2 * ++x + 3 * y++;
    cout << "Increment version x: " << x << ", y: " << y << ", z: " << z << endl;
    return 0;
}
```

2 способ с использованием оператора «запятая»
```
#include <iostream>
using namespace std;

int main() {
    int x = 5, y = 2, z = 10;
    (x = x + 1, z = z + 2 * x + 3 * y, y = y + 1);
    cout << "Comma version x: " << x << ", y: " << y << ", z: " << z << endl;
    return 0;
}
```

И в певром, и во втором способе получился одинаковый вывод: x=6, y=3, z=28.
Префиксный инкремент (++x) сначала увеличивает значение, а затем возвращает его. Подходит для строчки x = x + 1, чтобы сразу подставить новое значение для z.
Суффиксный инкремент (y++) сначала возвращает текущее значение для вычислений, а увеличение на 1 выполняет после. Подходит для переменной y. 

### Задание 3 **(2)**
*Рассмотрите следующий фрагмент программы. Он заполняет вектор из 10 элементов единицами.*
```
std::vector<int> x(10);
for (int i = 0; i < 10;)
   x[i++] = 1;
```
*Перепишите ее так, чтобы в третьей строке использовался префиксный инкремент, но результат ее работы не изменился.*
```
std::vector<int> x(10);
for (...)
   x[++i]=1;
```
 С суффиксным инкрементом программа работает так - сначала элемент вектора по текущему индексу i (i=0) заполняется единицей (x[0] = 1), а только после этого i увеличивается на 1. Снова запускается цикл, теперь i=1 - x[1] = 1 и так далее. Цикл корректно проходит по всем индексам.
Если просто заменить суффиксный инкремент на префиксный инкремент, программа не будет работать корректно. Так как мы просто пропустим индекс, который равен нулю и сразу же начнем с индекса 1. А также в конце программы обратились бы к индексу 10, которого не существует.

Правильный фрагмент программы с использованием префиксного инкремента:
```
std::vector<int> x(10);
for (int i = -1; i < 9;)
    x[++i] = 1;
```

Чтобы мы изначально с префиксным инкрементом обратились к индексу, который равен 0, нужно начать цикл с i=-1. А в конце программы, чтобы не возвращаться к несуществуещему индексу 10, также в цикле следует изменить конечное значение i < 9. С префиксным инкрементом 8 увеличится до индекса - 9, заполнится единицой и цикл закончится.
