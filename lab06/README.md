В этих вариантах разные ключивые слова: const и constexpr. Их отличие в том что const - константный объект, который создается во время работы программы. ### Задание 2 **(2)**
*Проверьте работу следующей программы на С++*
```
#include <iostream>
int main() {
   {
      int x, y;
      std::cin >> x >> y;
      std::cout << x+y << std::endl;
   }
   {
      double x, y;
      std::cin >> x >> y;
      std::cout << x+y << std::endl;
   }
   return 0;
}
```
*Нужны ли в этой программе вложенные фигурные скобки? Дайте подробный ответ с объяснением причин.*

Фигурные скобки нужны в этой программе. По правилам С++, в пределах одного и того же блока нельзя объявлять переменные с одинаковыми именами. В первом блоке создаются переменные int x, y, они есть только внутри этих фигурных скобок (внутри этого блока), то есть после закрыте фигурной скобки переменные удаляются из памяти компьютера и мы можем их использовать снова в другом блоке, как в примере (double x, y в следущем блоке). Если мы уберем вложенные фигурные скобки, то программа не будет компилироваться, потому что будут две переменные с одиноковым именем в одном блоке - int x, y и double x, y.

### Задание 5 **(2)**

*Напишите свой пример программы на* **С++**, *создающий и использующий пространства имен. Программа
должна содержать не менее двух пространств имен.*

```
#include <iostream>

namespace Add {
    int f(int a, int b) {
        return a + b;
    }
}

namespace Mul {
    int f(int a, int b) {
        return a * b;
    }
}

int main() {
    std::cout << Add::f(5, 3) << std::endl;

    std::cout << Mul::f(5, 3) << std::endl;

    return 0;
}
```
Я создала два пространства имен, первое отвечает за сложение( add), второе за умноение (mul), а внутри них функция, которая принимает два числа. В add складывает эти два числа, а в mul умножает. 
В коде две функции с одинаковым именем, если бы я написала их без пространства имен, была бы ошибка компиляции (из-за конфликта имен). Тк есть пространства имен, при выводе мы указываем какую именно функцию нужно посчитать например, Add::f(5, 3). Компилятор понимает, что нужно взять функцию f, которая отвечает за сложение. Тем самым никаких ошибок не вызывает и код успешно компилируется.

### Задание 6 **(2)**

*Рассмотрим следующий фрагмент программы. Эта программа 1000000 раз обменивает значения двух длинных 
строк с использованием третьей строки. Проверьте, насколько быстро она работает.*

```
std::string a(100000, 'a');
std::string b(100000, 'b');
for (int i=0;i<1000000;i++) {
   std::string c(a);
   a = b;
   b = c;
}
std::cout << a[0] << b[0];
```
*Попробуйте использовать для обмена значений строк функцию* **swap**. 
*Проверьте, изменилось ли время работы. В чем ошибка исходной программы?
Исправьте исходную программу, чтобы ускорить ее работу. Изменения не должны 
затрагивать общий вид программы (присваивания, использование временной переменной).*

```
#include <iostream>
#include <string>
#include <utility>

int main() {
    std::string a(100000, 'a');
    std::string b(100000, 'b');

    for (int i = 0; i < 1000000; i++) {
        std::string c = std::move(a);
        a = std::move(b);
        b = std::move(c);
    }

    std::cout << a[0] << b[0] << std::endl;
    return 0;
}
```
Я изменила код, работа программы изменилась, она стала работать в разы быстрее, чем до этого. В исходной программе, в строке std::string c(a) выделяется место, куда копируются все 100 000 символов из строки а. В строке a = b, стирается старая а и снова копируются 100 000 символов из b в а. И в строке b = c происходит такое же копирование 100 000 символов. Получается за 1 000 000 программа выполнит огромный и ненужный объём работы. Поэтому работа программы длится несколько секунд.
При использовании swap и программа стала работать быстрее. Но если оставить код с swap меняется вид программы (временная переменная c исчезает из кода):
```
#include <iostream>
#include <string>
#include <algorithm>

int main() {
    std::string a(100000, 'a');
    std::string b(100000, 'b');

    for (int i = 0; i < 1000000; i++) {
        std::swap(a, b);
    }

    std::cout << a[0] << b[0] << std::endl;
    return 0;
}
```
Поэтому я заменила swap на std::move(). Из за этого больше не нужны данные из строки а, вместо физического копирования текста просто копируются указатели на него. Тем самым увеливая скорость работы.

### Задание 7 **(2)**

*Рассмотрим программу на языке* **Python**.
```
a = 'Hello world'
print(a, id(a))
b = a
print(b, id(b))
a += ' and goodbye'
print(a, id(a))
print(b, id(b))
```
*Объясните ее работу. В какой момент создавались строки? 
Что означает значение, возвращенное функцией* **id**?

Функция id() возвращает уникальный адрес объекта в памяти компьютера. Если у двух переменных id одинаковый, это значит, что они указывают на один и тот же объект в памяти.
a = 'Hello world' - в памяти СОЗДАЕТСЯ СТРОКА, переменная а указывает на эту строку. id(a) вернет адрес этой строки.
b = a - в Python это означает копирование ссылки (а не текста). Поэтому НОВАЯ СТРОКА НЕ СОЗДАЕТСЯ. Это означает, что переменная b указывает на ту же строку, что и переменная а.
a += ' and goodbye' - строки в Python не изменяемые, поэтому текст не может быть дописан в старую строку. Он берет Hello world из первой строки и добавляет and goodbye. Тем самым СОЗДАЕТСЯ НОВАЯ СТРОКА и перенаправляет переменную а на неё (b все также указыает на првую строку)
Следовательно id(a) покажет адрес новой строки, а id(b) покажет адрес старой строки.

###  Задание 9 **(3)**
*Напишите программу на языке* **Python**, *которая создаст 2600 переменных с именами
от* **a0** *до* **a99**, *от* **b0** *до* **b99** *и так далее, от* **z0** *до* **z99**. 
*Присвойте всем переменным различные значения от 1 до 2600.*

```
value = 1
alphabet = "abcdefghijklmnopqrstuvwxyz"

for letter in alphabet:
    for num in range(100):
        name = f"{letter}{num}"
        
        globals()[name] = value
        value += 1

print(a0) 
print(z99)
```
Написать 2600 переменных вручную в коде невозможно. Но в Python все переменные лежат в специальном системном словаре, к которому можно обратиться через команду globals().
Я сделала простой двойной цикл: первый перебирает буквы алфавита, а второй — цифры от 0 до 99. Программа склеивает их в имена (вроде a0, b55) и через globals() добавляет их как переменные в память компьютера, сразу выдавая им значения от 1 до 2600. Две строчки print в конце доказывают, что переменные создались и работают
